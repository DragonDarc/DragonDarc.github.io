# MRLCOM โรงเรียนมาเรียลัย

เว็บไซต์รวมกิจกรรม ค่าย การแข่งขัน และโอกาสทำพอร์ตสำหรับนักเรียน โรงเรียนมาเรียลัย ออกแบบธีมไซไฟ พร้อมฉากนักเรียนและเอฟเฟกต์เลื่อนหน้าแบบ cinematic / parallax

เวอร์ชันนี้เผยแพร่บน **GitHub Pages ของเจ้าของ repository** และทำงานแยกจาก ChatGPT ไม่ต้องใช้ ChatGPT Plus, API key, ฐานข้อมูลบน Sites หรือบริการโฮสต์ของ ChatGPT

## ฟีเจอร์ที่พร้อมใช้

- แบ่งสายวิทย์–เทคโนโลยี / ศิลป์–ภาษา พร้อมหมวดและรูปแบบผลงานย่อย
- ค้นหา กรองระดับชั้น วันปิดสมัคร พื้นที่และค่าใช้จ่าย
- หน้ารายละเอียด ลิงก์ผู้จัด ปฏิทินกิจกรรม ดาวน์โหลดไฟล์ปฏิทินและรายการ CSV
- บันทึกกิจกรรมที่สนใจในเบราว์เซอร์ ไม่ต้องสมัครสมาชิก
- ข้อมูลสาธารณะเริ่มต้น 130 รายการ และตัวอ่านข่าวเดิม 10 แหล่ง
- GitHub Actions สำหรับตรวจข่าวจากต้นทางและเผยแพร่ประมาณทุก 6 ชั่วโมง
- รองรับมือถือและการลดการเคลื่อนไหวผ่านการตั้งค่าของอุปกรณ์หรือปุ่มบนหน้าเว็บ

ฉากเปิดใช้ภาพนิ่งพร้อมการเลื่อนและพารัลแลกซ์ ไม่ใช่วิดีโอตัวละครเคลื่อนไหว

## เว็บไซต์ที่เผยแพร่จริง

- เว็บนักเรียน: https://dragondarc.github.io/mrlcom/
- บัญชีเจ้าของ: **DragonDarc**
- Repository: https://github.com/DragonDarc/DragonDarc.github.io
- ซอร์ส: โฟลเดอร์ `_mrlcom-source/`
- ไฟล์ที่เผยแพร่: โฟลเดอร์ `mrlcom/`
- Workflow: `.github/workflows/mrlcom.yml` ชื่อ **Update MRLCOM**

GitHub Pages ของบัญชีนี้เผยแพร่จาก branch `main` ที่ราก repository โฟลเดอร์ `mrlcom/` เป็นส่วนใหม่ของเว็บไซต์ ส่วนซอร์สที่ขึ้นต้น `_` ไม่ถูก Jekyll นำไปเผยแพร่เป็นหน้าเว็บ

แก้โค้ดหรือ `public/data/school-activities.json` ภายใน `_mrlcom-source/` แล้ว Commit ได้เลย Workflow จะสร้างไฟล์และขอให้ GitHub Pages เผยแพร่เว็บใหม่ ไม่ต้องตั้งค่า ChatGPT หรือ API key

## การอัปเดตข่าว

- ตรวจข่าวจากเว็บไซต์ต้นทางโดยตรง ไม่เรียกเว็บเก่าบน `chatgpt.site`
- กำหนดไว้ที่นาที 17 ของทุก 6 ชั่วโมงตามเวลา UTC ประมาณ 01:17 / 07:17 / 13:17 / 19:17 น. เวลาไทย
- GitHub อาจเริ่มรอบงานช้าหรือข้ามบางรอบได้ จึงไม่ใช่ข้อมูลเรียลไทม์
- หากแหล่งข่าวอ่านไม่ได้ เก็บรายการเดิมไว้และแสดงสถานะอ่านไม่สำเร็จ
- ปุ่ม “โหลดข้อมูลล่าสุด” บนเว็บอ่านไฟล์จาก deployment ล่าสุด ไม่สั่งให้เซิร์ฟเวอร์ไปดึงข่าวทันที หากต้องการตรวจทันที เจ้าของเปิด **Actions → Update MRLCOM → Run workflow → refresh = true**
- กำหนดการอาจถูกพักหาก repository สาธารณะไม่มีกิจกรรมเป็นเวลานาน เจ้าของเปิดตรวจใน Actions และเปิด workflow อีกครั้งได้
- ข้อมูลข่าวและสถานะแหล่งข้อมูลที่อัปเดตจะถูกบันทึกกลับ `_mrlcom-source/public/data/activities.json` ด้วยบัญชีบอตของ GitHub หากกฎ branch ไม่อนุญาต บางรอบอาจบันทึกประวัติกลับไม่ได้ และ workflow จะแสดงข้อผิดพลาดเพื่อให้เจ้าของตรวจสิทธิ์การเขียน

เอกสาร GitHub: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages), [การเผยแพร่ด้วย Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [ข้อจำกัดรอบงานตามเวลา](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)

## เพิ่มประกาศที่โรงเรียนแนะนำ

ครูแก้ไฟล์ `_mrlcom-source/public/data/school-activities.json` ใน GitHub แล้วกด Commit ได้เลย ระบบจะเผยแพร่อีกครั้งโดยอัตโนมัติ สิทธิ์แก้ประกาศขึ้นกับสิทธิ์ของ repository จึงไม่มีหน้าเข้าสู่ระบบผู้ดูแลบนเว็บ

เริ่มต้นไฟล์นี้เป็น `[]` หากจะเพิ่มประกาศให้แทนด้วย array ของรายการต่อไปนี้ แก้ข้อความตัวอย่างและ URL ให้เป็นประกาศจริงก่อนบันทึก:

```json
[
  {
    "id": "school-example-01",
    "title": "ใส่ชื่อกิจกรรมจริง",
    "organizer": "ใส่ชื่อผู้จัดจริง",
    "source": "school",
    "url": "https://example.org/ใส่ลิงก์ประกาศจริง",
    "category": "computer",
    "kind": "competition",
    "summary": "ใส่รายละเอียดกิจกรรมที่ตรวจจากประกาศจริง",
    "levels": ["ม.4", "ม.5", "ม.6"],
    "deadline": null,
    "startDate": null,
    "endDate": null,
    "fee": null,
    "feeNote": "ตรวจสอบค่าใช้จ่ายกับผู้จัด",
    "location": "ดูในประกาศ",
    "area": "unknown",
    "team": "ตรวจสอบคุณสมบัติกับผู้จัด",
    "tags": ["โรงเรียนแนะนำ"],
    "reviewed": false,
    "needsReview": true,
    "checkedAt": "2026-10-19T00:00:00.000Z",
    "fetchedAt": null,
    "publishedAt": null,
    "custom": true
  }
]
```

- `id` ต้องไม่ซ้ำและขึ้นต้น `school-` พร้อม `custom: true`
- `category`: `computer`, `science`, `math`, `engineering`, `creative`, `language`
- `kind`: `competition`, `camp`, `workshop`
- `area`: `bangkok`, `other`, `online`, `unknown`
- วันใช้ ค.ศ. รูปแบบ `YYYY-MM-DD` หรือ `null` เมื่อยังไม่ทราบ
- ค่าใช้จ่าย `0` หมายถึงไม่มีค่าสมัคร `null` หมายถึงยังไม่ทราบ
- ตรวจคุณสมบัติและวันสมัครครบแล้วจึงตั้ง `reviewed: true` และ `needsReview: false`
- เมื่อลบรายการออกจากไฟล์นี้ รายการนั้นจะหายจากการเผยแพร่ครั้งต่อไป

## การบันทึกรายการที่สนใจ

รายการเก็บใน localStorage ของเบราว์เซอร์บนโดเมน GitHub Pages ไม่ซิงก์ข้ามเครื่อง และอาจหายเมื่อล้างข้อมูลเว็บไซต์หรือใช้งานโหมดส่วนตัว ใช้ปุ่มดาวน์โหลด CSV เพื่อเก็บสำเนาได้

รายการส่วนตัวที่เคยบันทึกผ่านบัญชี ChatGPT ในเว็บเดิมไม่ได้ย้ายมาด้วย โครงการนี้มีเฉพาะข้อมูลกิจกรรมสาธารณะ ไม่มีข้อมูลบัญชีหรือรายการส่วนตัวของนักเรียน

## ทำงานในเครื่อง

ใช้ Node.js 24 ขึ้นไป และเปิด terminal ในโฟลเดอร์ `_mrlcom-source/`:

```bash
npm ci
npm run dev
```

ตรวจและสร้างไฟล์เผยแพร่:

```bash
npm test
npm run build
```

ผลลัพธ์อยู่ใน `dist/` หากสร้างด้วยตนเองให้กำหนด `SITE_URL` เป็น URL เว็บจริงเพื่อสร้าง canonical และ sitemap ด้วย Workflow ใน repository นี้ทำขั้นตอนนี้อัตโนมัติ

ตรวจต้นทางจากเครื่อง:

```bash
npm run update:data
```

หรือเลือกแหล่งข่าวเดียว เช่น `npm run update:data -- posn` การตรวจไม่ต้องมี API key และบางแหล่งอาจบล็อกการอ่านอัตโนมัติ

## สิ่งที่ต่างจากเว็บเดิมบน Sites

| ส่วน | GitHub Pages เวอร์ชันนี้ |
| --- | --- |
| โฮสต์ | GitHub ของเจ้าของ repository |
| บัญชี ChatGPT | ไม่ใช้ |
| รายการกิจกรรม | ไฟล์ JSON สาธารณะใน repository |
| ตรวจข่าว | GitHub Actions ตามรอบ หรือเจ้าของสั่ง Run workflow |
| บันทึกรายการส่วนตัว | เก็บในเบราว์เซอร์ |
| เพิ่ม/แก้ประกาศโรงเรียน | แก้ไฟล์ใน GitHub ภายใต้สิทธิ์ของเจ้าของ |
| เว็บไซต์ Sites เดิม | ทำงานแยกกัน ไม่ถูกแก้ไขหรือลบโดยการติดตั้งนี้ |

การค้นพบเว็บผ่านเครื่องมือค้นหาขึ้นกับการเก็บข้อมูลของแต่ละบริการ การมี sitemap ไม่รับประกันวันหรืออันดับที่จะแสดงในผลค้นหา
